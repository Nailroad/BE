# Nailroad BE

## 서비스 소개

네일로드는 원하는 네일 디자인을 찾고, 네일샵에 견적을 요청해 시술을 예약하는 서비스입니다.

## 기술 스택

- Java 21
- Spring Boot 4.1.2 · Spring MVC
- Gradle Wrapper 9.8.2
- SpringDoc OpenAPI 3.2.0
